## 📷 내 사진 — 지한이가 아는 것으로 놀기

앱에서 **내 사진 → 사진 넣고 빼기 → 사진 고르기** 를 누르고, 폰에 있는 사진을 골라 이름을 적으면 끝이다.
여러 장을 한 번에 골라도 되고, 여러 개가 한 장에 모여 있는 그림(캐릭터 도감 같은)은
**🔳 모아놓은 사진 잘라서 넣기** 로 칸칸이 잘라서 한 번에 넣을 수 있다.
장난감, 우리 집 차, 동네 소방차, 가족 사진 — 지한이가 실제로 아는 것으로 놀 수 있다.

- 넣은 사진은 **이 기기 안(브라우저 저장소)에만** 저장된다. 인터넷으로 올라가지 않고, 저장소에도 들어가지 않는다
- 4장을 넘겨 넣으면 놀이 4개가 모두 열린다
- 사진은 자동으로 정사각형 480px로 줄여서 저장한다

## 게임

| 게임 | 하는 일 | 키우는 능력 | 난이도 |
|---|---|---|---|
| 👂 **듣고 찾기** | "덤프트럭 어디 있어?" 들려주면 찾아 누르기 | 어휘력, 청각 주의집중 | 6 → 9 → 12개 중에서 |
| 🔍 **다른 거 찾기** | 같은 무리 속에 섞인 하나 고르기 | 범주화 사고 | 6개 → 9개 → 9개(비슷한 주제끼리) |
| 🔎 **확대 맞추기** | 사진의 한 부분만 크게 보고 원래 사진 찾기 | 부분에서 전체를 떠올리는 힘 | 2.3배 → 3.2배 → 4.6배 확대 |
| 🧩 **퍼즐** | 빈 판에 조각을 **끌어다 끼우기** (진짜 퍼즐처럼 돌기·홈이 맞물린다) | 공간지각, 끈기 | 3×3 → 4×4 → 5×5 → 6×6 |
| 🫥 **없어진 거** | 잠깐 보여준 뒤 하나를 빼고, 없어진 걸 찾기 | 시각 작업기억 | 4 → 6 → 8장 |
| 🔢 **몇 개일까** | 위와 같은 개수를 아래에서 고르기 | 수 감각 (숫자를 못 읽어도 됨) | 1~3 → 1~5 → 1~7개 |
| ➡️ **다음은 뭘까** | 규칙대로 늘어놓은 줄의 다음 칸 맞히기 | 계열 추론 | ㄱㄴㄱㄴ → ㄱㄱㄴㄴ → ㄱㄴㄷ |
| 👆 **순서대로** | 들려준 순서 그대로 누르기 | 청각 기억폭 | 2 → 3 → 4개 |
| 🌍 **어디 있을까** | 이게 어디 사는지 고르기 (바다·철길·도로·공사장·초원) | 상식·관계 추론 | 3 → 4 → 5곳 |
| 🎈 **풍선 터뜨리기** | 떠오르는 풍선 중 부르는 것만 터뜨리기 | 시각 탐색 + **참는 힘** | 풍선 3 → 5 → 7개, 점점 빨라짐 |
| 🔦 **손전등 찾기** | 깜깜한 화면에서 손가락 댄 곳만 밝아진다 | 지속 주의력, 어디를 봤는지 기억하기 | 6 → 9 → 12장, 불빛은 점점 작게 |
| 🎨 **색칠하기** | 밑그림 칸을 눌러 색을 채운다. **빨주노초파남보 + 5색** | 색 이름, 계획하기, 만드는 즐거움 | 단계 없음 (쉬어가는 놀이) |
| 🎤 **따라 말하기** | 이름을 듣고 따라 한 뒤 자기 목소리를 들어본다 | 발음 연습, 자기 소리 듣기 | 단계 없음 |
| 🎹 **피아노** | 자유롭게 치고, 들려준 대로 따라 친다 | 소리 기억, 박자 | 따라 치기 2 → 3 → 4 → 5음 |
| 👆 **점 잇기** | 1→2→3 순서대로 점을 이으면 그림이 나온다 | **숫자 모양 익히기**, 순서 | 점 3~7 → 7~10 → 10~12개 |
| 🌀 **미로** | 손가락으로 길을 따라 깃발까지 | 미리 생각하기, 소근육 | 4×4 → 5×5 → 6×6 |
| 📏 **크기 순서** | 작은 것부터 큰 것까지 차례로 놓기 | 서열화 (수의 크기를 이해하는 바탕) | 3 → 4 → 5개 |
| 🎯 **담기** | 색·모양이 같은 통에 담기 | 속성 분류 (같은 것을 색으로도 모양으로도 묶을 수 있다) | 통 2 → 3 → 4개 |

> 뒤의 다섯은 **사진을 쓰지 않는다.** 어느 주제에서나 똑같이 나온다.
> 🎹 피아노와 🎨 색칠하기는 문제를 푸는 게 아니라서 지칠 때 쉬어가는 자리가 된다.

### 📷 사진 넣으면 바로 퍼즐

퍼즐 화면 위 **📷 내 사진으로** 를 누르고 폰 사진을 고르면, **이름을 적지 않아도 곧바로
그 사진 퍼즐이 시작된다.** 한 판을 끝내면 같은 사진이 더 잘게 나뉘어 어려워진다.
**🖼️ 원래 사진** 을 누르면 되돌아간다.

내 사진 목록(**내 사진 → 사진 넣고 빼기**)에서도 사진마다 붙은 **🧩** 를 누르면
그 사진으로 바로 퍼즐이 열린다.

### 퍼즐은 이렇게 만들었다

- **빈 판 + 쟁반.** 조각은 아래(가로모드에선 옆) 쟁반에 있고, 끌어다 판에 끼운다.
  끌기가 어려우면 **조각을 눌렀다가 칸을 누르는 것**으로도 된다
- **제자리가 아니면 들어가지 않는다.** 실제 퍼즐처럼, 맞는 칸에만 들어간다
- **완성 그림을 옅게 깔아뒀다.** 어디에 뭐가 들어가는지 보여야 포기하지 않는다
- **조각에 단서가 없는 사진은 쓰지 않는다.** 하늘·물처럼 단색 영역이 큰 사진은
  그 조각을 맞출 방법이 없다. 조각마다 무늬가 얼마나 있는지 재서 87장 중
  53장만 퍼즐에 쓴다 (`js/puzzleok.js`)
- **내 사진도 같은 잣대로 거른다.** 도감을 잘라 넣은 카드처럼 흰 여백이 많은 사진은
  퍼즐에 나오지 않는다. 사진을 넣을 때 브라우저가 직접 재고, 예전에 넣어둔 사진은
  앱을 켤 때 한 번 재서 기록해 둔다
- 다만 **🧩 나 📷 로 직접 고른 사진은 그대로 쓴다.** 부모가 정한 것이기 때문이다
- 쟁반에는 한 번에 8조각까지만 보여준다. 36조각을 한꺼번에 늘어놓으면 질린다

### 🏆 모으기 도감

게임에서 맞출 때마다 그 사진이 도감에 채워진다. 홈 오른쪽 위 🏆 를 누르면 주제별로
몇 개나 모았는지 보인다. 처음 모은 것은 칭찬 화면에 **"새 스티커!"** 가 뜬다.
빈 칸이 채워지는 걸 보면 나머지를 채우고 싶어져서, 나머지 놀이가 다 재밌어진다.

> `어디 있을까` 는 사는 곳을 알 수 있는 주제에서만 나온다. `내 사진` 주제에서는 메뉴에 보이지 않는다.
> `순서대로` 는 들려줄 때만 글자를 같이 보여주고, 누를 때는 가린다.

### 난이도가 저절로 맞춰진다

- **연속으로 맞추면** 한 단계 어려워진다 ("더 어려운 거 해볼까?")
- **연속으로 틀리면** 조용히 한 단계 쉬워진다 (아이는 눈치채지 못한다)
- 단계는 게임별·주제별로 따로 기억된다. 게임 메뉴의 ★ 개수가 지금 단계다

### 틀렸을 때는 혼내지 않는다

살짝 흔들리고 다시 찾아보게 할 뿐이다. 색종이·딩동댕·큰 글씨 같은 **보상은 맞췄을 때만** 나온다.

## 내용 바꾸기

### 단어 추가·수정

`js/data.js` 의 목록만 고치면 **게임 4개가 전부 같이 바뀐다.**

```js
{ id: 'firetruck', name: '소방차' }
{ id: 'ktx', name: 'KTX', say: '케이티엑스' }   // say = 읽어줄 말
```

- `name` 을 바꾸면 화면 글자와 읽어주는 말이 같이 바뀐다
- 화면 글자와 읽는 말이 달라야 하면 `say` 를 따로 적는다 (KTX → "케이티엑스")
- 새 단어를 넣으려면 여기에 한 줄 추가하고 `img/<주제>_<id>.jpg` 에 정사각형 사진을 넣는다
- 사진이 없는 항목은 `js/photos.js` 목록에 적혀 있고 게임에 나오지 않는다. 사진을 넣었으면 그 줄을 지운다

### 난이도 초기화

개발자도구 콘솔에서:

```js
Level.reset(); location.reload();
```

## 아이가 쓰는 앱이라 챙긴 것

- **드래그 없음.** 오직 탭. 퍼즐도 조각 두 개를 차례로 눌러 자리를 바꾼다
- **뒤로가기는 1.2초 길게 눌러야 동작한다.** 실수로 나가서 우는 일 방지
- **버튼이 크다.** 타일은 화면 높이에도 맞춰 커진다
- **틀려도 벌이 없는 놀이가 있다.** 풍선은 틀리면 흔들리고 날아갈 뿐이고,
  손전등은 틀린 곳을 눌러도 그냥 그 자리가 밝아진다. 겁내지 않고 눌러봐야 는다
- **글자를 항상 같이 보여준다.** 글자를 배우는 중이라, 소리와 글자를 잇는 게 읽기의 시작이다
- **가로·세로 어느 쪽으로 들어도 잘 나온다.** 칸 수를 화면 모양에 맞춰 스스로 정하고,
  가로모드에서는 문제를 왼쪽에 두고 고르는 곳을 오른쪽에 둔다.
  돌리는 도중에도 놀던 내용은 그대로 두고 배치만 다시 잡는다

## 안 하는 것

**개인정보 수집 0건, 광고·결제 0개.** 기록·내 사진·색칠한 그림·녹음한 목소리는 모두 기기 안에만 남는다.

## 알아둘 것

- **한국어 음성은 기기에 깔려 있어야 나온다.** 안드로이드 크롬은 보통 있다.
  없으면 `설정 → 접근성 → 텍스트 음성 변환` 에서 한국어를 받으면 된다
- **아이폰은 측면 무음 스위치가 켜져 있으면** 웹앱 소리가 안 난다. 브라우저 정책이라 코드로 못 고친다
