# 지한이 놀이터

30개월 지한이를 위한 놀이 웹앱. 설치 없이 주소만 열면 폰·태블릿에서 바로 돌아간다.

**주제 4개 × 게임 5개 = 20가지 놀이.** 그림과 소리로만 안내하고, 단어는 항상 큰 글자로 같이 보여준다.

## 여는 법

### 1. GitHub Pages 켜기 (처음 한 번만)

저장소 → **Settings** → 왼쪽 **Pages** → Source 를 **Deploy from a branch**,
Branch 를 **main** (또는 이 브랜치) / **/(root)** 로 지정하고 **Save**.

1~2분 뒤 이 주소로 열린다:

```
https://xichx22.github.io/limach/
```

### 2. 홈 화면에 추가하기 (앱처럼 쓰기)

- **안드로이드 크롬**: 주소 열고 → 오른쪽 위 ⋮ → `홈 화면에 추가`
- **아이폰 사파리**: 공유 버튼 → `홈 화면에 추가`

추가하면 주소창 없이 전체화면으로 뜨고, **인터넷이 없어도 돌아간다** (차 안, 지하철).

## 게임 5개

| 게임 | 하는 일 | 키우는 능력 | 난이도 |
|---|---|---|---|
| 👂 **듣고 찾기** | "굴절사다리차 어디 있어?" 들려주면 찾아 누르기 | 어휘력, 청각 주의집중 | 6 → 9 → 12개 중에서 |
| 🔍 **다른 거 찾기** | 같은 무리 속에 섞인 하나 고르기 | 범주화 사고 | 6개 → 9개 → 9개(비슷한 것끼리) |
| 🌑 **그림자 맞추기** | 검은 실루엣 보고 원래 그림 찾기 | 형태 인지, 추상화 | 4 → 6 → 9지선다 |
| 🧠 **짝 맞추기** | 카드 뒤집어 같은 그림 찾기 | 작업기억력 | 12 → 16 → 20장 |
| 🧩 **퍼즐** | 조각 두 개를 눌러 자리 바꾸기 | 공간지각, 끈기 | 4×4 → 5×5 → 6×6 |

### 난이도가 저절로 맞춰진다

- **연속으로 맞추면** 한 단계 어려워진다 ("더 어려운 거 해볼까?")
- **연속으로 틀리면** 조용히 한 단계 쉬워진다 (아이는 눈치채지 못한다)
- 단계는 게임별·주제별로 따로 기억된다 (기기 안에만 저장)
- 게임 메뉴의 ★ 개수가 지금 단계다

### 틀렸을 때는 혼내지 않는다

살짝 흔들리고 다시 찾아보게 할 뿐이다. 색종이·딩동댕·큰 글씨 같은 **보상은 맞췄을 때만** 나온다.

## 내용 바꾸기

### 단어 추가·수정

`js/data.js` 의 `THEMES` 만 고치면 **게임 5개가 전부 같이 바뀐다.**

```js
{ id: 'sedan', name: '승용차', emoji: '🚗' }
```

- `name` 을 바꾸면 화면에 뜨는 글자와 읽어주는 말이 같이 바뀐다.
  예: 지한이가 "산타페"라고 부르면 `name: '산타페'` 로 바꾸면 된다.
- 새 주제를 통째로 넣어도 된다 (예: 공룡). 게임 5개가 자동으로 늘어난다.

### 특수자동차 그림 고치기

`js/art.js` 에 12종이 SVG로 그려져 있다. 전부 옆모습, 같은 크기(120×70)라
그림자 맞추기에서 실루엣이 제대로 비교된다.
물줄기처럼 **그림자가 안 생기는 부분**은 `class="no-shadow"` 를 붙이면 실루엣에서 빠진다.

### 퍼즐 그림 고치기

`js/data.js` 의 `SCENES`. 배경 위에 그림을 흩뿌리는 방식이라,
`{ e: '🐋', x: 38, y: 22, s: 28 }` 처럼 한 줄 추가하면 된다 (x·y·크기는 전체를 100으로 본 %).
6×6(36조각)까지 가기 때문에 **어느 조각에나 단서가 보이도록** 촘촘히 채워야 한다.

### 난이도 초기화

브라우저 주소창에 `about:blank` 대신 개발자도구 콘솔에서:

```js
Level.reset(); location.reload();
```

## 아이가 쓰는 앱이라 챙긴 것

- **드래그 없음.** 오직 탭. 퍼즐도 조각 두 개를 차례로 눌러 자리를 바꾼다
- **뒤로가기는 1.2초 길게 눌러야 동작한다** (동그란 진행 표시가 채워진다). 실수로 나가서 우는 일 방지
- **버튼이 크다.** 타일은 화면 높이에도 맞춰 커져서, 6개일 때와 12개일 때 모두 화면을 꽉 채운다
- **글자를 항상 같이 보여준다.** 지한이가 글자를 배우는 중이라, 소리와 글자를 잇는 게 읽기의 시작이다

## 안 하는 것

**외부 접속 0건, 개인정보 수집 0건, 광고·결제 0개.** 기록은 기기 안(localStorage)에만 남는다.

---

## 알아둘 것

- **한국어 음성은 기기에 깔려 있어야 나온다.** 안드로이드 크롬은 보통 있다.
  없으면 `설정 → 접근성 → 텍스트 음성 변환` 에서 한국어를 받으면 된다.
  음성이 없으면 앱이 알려주고, 글자와 효과음으로만 돌아간다.
- **아이폰은 측면 무음 스위치가 켜져 있으면** 웹앱 소리가 아예 안 난다. 브라우저 정책이라 코드로 못 고친다.
- **이모지는 기기마다 조금씩 다르게 보인다** (삼성·애플·구글 디자인 차이). 노는 데 지장은 없다.

## 만듦새

라이브러리·빌드도구 없는 순수 HTML + CSS + JavaScript. 이미지 파일과 음원 파일이 하나도 없다.
그림은 이모지와 SVG, 소리는 브라우저 내장 한국어 음성과 Web Audio 합성음으로 만든다.

```
index.html              화면 틀
css/style.css
js/sound.js             음성 + 효과음
js/art.js               특수자동차 12종 SVG
js/data.js              주제 4개 × 단어, 퍼즐 장면 8개   ← 내용은 여기만
js/level.js             난이도 자동 조절
js/engine.js            화면 전환, 타일, 칭찬 효과, 부모 잠금
js/games/*.js           게임 5개
sw.js                   오프라인 실행
```
